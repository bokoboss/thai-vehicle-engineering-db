Evidence-aware feasibility screening

Design Check

Enter explicit site limits, then assess all or a filtered set of exact curated vehicle configurations. Unknown, conflicting, rejected, or semantically mismatched data remains INDETERMINATE.

Method DESIGN_CHECK_V1 · scenario state is held in the URL.

Screening boundary

This workflow checks only the entered minimum clear height, width envelope, overall length, and like-for-like turning-envelope semantics. It does not perform swept-path simulation, parking-aisle maneuver solving, collision/ramp-contact analysis, or regulatory/code compliance. No legal or recommended design limit is prefilled.

Site / design constraints

Every active constraint is an explicit upper-bound input. Leave a constraint limit blank to leave that check inactive.

Enter the minimum clear height after considering beams, sprinklers, signs, MEP, door equipment, slopes, and similar obstructions. The tool checks this entered minimum only. {{ field_error("available_clear_height_mm") }}
Blank is treated as 0 mm only when the height check is active; enter 0 explicitly when no additional allowance is required. {{ field_error("vertical_allowance_mm") }}
The clear opening available to the selected vehicle envelope before the explicit per-side allowance is deducted. {{ field_error("available_clear_width_mm") }}
Required when the width check is active. Effective limit = clear width − 2 × this allowance. {{ field_error("lateral_allowance_each_side_mm") }}
Definitions are not interchangeable. Body width is never substituted for mirrors-open or mirrors-folded width. {{ field_error("width_envelope") }}
Uses the curated overall length only; wheelbase and overhangs are not recombined here. {{ field_error("maximum_vehicle_length_mm") }}
Activates Turning-envelope screening. Enter a radius or diameter and the exact reference below. {{ field_error("maximum_turning_value_m") }}
The entered limit is normalized to radius internally with the versioned deterministic conversion. {{ field_error("turning_input_shape") }}
Vehicle reference must match exactly. OEM-unspecified reference remains INDETERMINATE. {{ field_error("turning_reference") }}
